# SeniorConnect


## Descrição

O SeniorConnect é uma plataforma educativa desenvolvida para promover a inclusão digital de idosos, auxiliando no aprendizado de ferramentas tecnológicas de forma simples, intuitiva e acessível.

O projeto foi desenvolvido como atividade extensionista do curso de Banco de Dados da UNINTER, com foco na comunidade do bairro Fazendinha, em Curitiba – PR.

## Objetivo

Promover a inclusão digital de idosos por meio de conteúdos educativos relacionados ao uso de smartphones e aplicativos.

## Funcionalidades

* Tutorial de WhatsApp
* Orientações para vídeo chamadas
* Segurança digital
* Prevenção contra golpes virtuais
* Ajuste de fonte para acessibilidade
* Leitura por voz
* Guia de ícones do celular
* Orientações sobre Wi-Fi
* Contato rápido

## Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
* Visual Studio Code

## ODS Atendido

ODS 4 – Educação de Qualidade

## Aplicação Comunitária

A plataforma foi apresentada a participante da comunidade do bairro Fazendinha, Curitiba – PR, com demonstração das funcionalidades relacionadas ao uso do WhatsApp e segurança digital.
